## Macy's runs two completely different kinds of discount

Most coupon hunting goes wrong because people treat these as one thing.

The first kind is the always-on offer. New subscribers get an extra 25% off their next purchase — Macy's own account-creation page states this for new email subscribers, with exclusions and one per customer. It's not glamorous, and it only fires once, but it's the one discount Macy's actually promises you.

The second kind is the labeled-item event. Macy's puts an extra-savings event on the homepage, gives it a word — right now that's been BEST for the seasonal sale, HOME for home events, EARLY for early access to a designer rollout, SUMMER and VIP for their own windows — and then applies a percentage to whichever items carry that label. The percentage depends on the category, not on your basket size. During a recent Best of the Season window, for example, the same BEST code was worth 15% on some eligible items and 30% on others.

That's the catch nobody mentions: with these events, you don't choose the discount. The item does. A code that gives you 30% off a coat can give you 10% off small appliances in the same transaction, and nothing at all on the bag sitting next to it.

## The Macy's rule that ruins most stacking plans

You get one promo code per transaction. Not two, not one code plus one extra-savings event. One.

Macy's extra-savings language is explicit about it too — labeled-item events like SUMMER note that the extra savings cannot be combined with any coupon or extra discount, with the single exception of opening a new Macy's account.

So when a coupon page promises you "stack three codes for 60% off," what it's describing is not a thing Macy's does. What you can genuinely layer isn't a second code. It's:

1. A sale price, which happens before any code touches the cart.
2. One code, on eligible items only.
3. Star Rewards points, earned on the amount you actually pay.
4. Cashback from a shopping portal, if the code you used doesn't disqualify you.

Four layers is a good outcome. Anyone promising you six has never applied a code at Macy's checkout.

## The exclusion list is where orders go sideways

Macy's exclusion lists are long, and they're not buried — they're published on Macy's own promotional-details pages, which is a tell that the retailer knows people will be annoyed.

The categories that repeatedly get carved out:

- Designer and premium brands
- Apple products
- Furniture and mattresses (on many offers)
- Cosmetics and fragrance on most coupon codes, which is exactly why Star Passes exist
- Last Act Clearance, Backstage, and Macy's Wine Shop
- Gift cards, services, fees and sales tax

Practical version: if your basket is one designer handbag and a lipstick, expect the code to fire on the lipstick at best. The way to check before you commit is to add everything to your bag and look at the savings line. Macy's shows you the applied discount per item, so you find out in the cart instead of after you've paid.

## Common questions, answered without the runaround

**Does Macy's have a code that works today?**
The new-subscriber 25% offer, app-exclusive codes, Star Passes for members, and whatever labeled-item event is running. The first two you can claim for yourself in a few minutes.

**Can I stack two Macy's codes?**
No. One promo code per transaction, and labeled-item extra-savings events explicitly rule out combining with coupons.

**Can I stack a coupon with cashback?**
Yes, with a condition — the code has to be the one listed on the cashback platform. A code from elsewhere can void the cashback.

**Does Macy's have a student discount?**
No standing student, teacher or military program. Signup offers and seasonal sales are where the savings come from.

**What's the best thing to do if I don't qualify for any code?**
Join Star Rewards and shop the sale sections. Bronze gets you free shipping at $39 instead of $49 and points on everything; sale pricing plus a shipping threshold you actually clear often beats a coupon that half-applies.

**Why does my code work on one item and not another?**
Because labeled-item events discount per item, and Macy's owns a long exclusion list — designer brands, Apple, beauty, furniture and clearance among them. Check the savings line in your bag before checkout.
